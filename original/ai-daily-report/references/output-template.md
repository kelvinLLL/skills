---

## 一、基础设施与算力

**🔴 标题**
核心内容一句话。
[来源名称 · YYYY-MM-DD](https://...)

**🟡 标题**
核心内容一句话。
[来源名称 · YYYY-MM-DD](https://...)

（如无今日动态：> 今日暂无重大动态）

---

## 二、模型与研究

（同上格式，覆盖全模态：LLM / 代码 / 图像生成 / 视频生成 / 音频 / 多模态 / Agent框架）

（HuggingFace Papers热门 / arXiv热门 / GitHub Trending AI仓库 / Reddit热帖 / HN热帖）

每条格式：

## 质量控制规则

| 规则 | 说明 |
|------|------|
| 日期硬约束 | 每条必须标注【来源 · 日期 · URL】，超出 ±2 天直接丢弃 |
| URL 必填 | 无法确认 URL 的条目降级为🟡并标注"来源待核实"，不得凭空捏造 URL |
| 模态覆盖 | 视频/图像/音频生成模型与文字模型同等重要，不能遗漏 |
| 最低条数 | 每板块至少 5 条，目标 8-10 条；不足时必须扩大搜索，不得以"今日暂无"敷衍 |
| 去重 | 同一事件只在最相关板块出现 |
| 空板块 | 只有穷尽所有来源仍无内容时才写"今日暂无重大动态" |
| 高优先级核实 | 🔴 条目必须 webfetch 官方源确认日期 |
| 重要性必须区分 | 每板块至少 1 条 🔴，不得全部标为 🟡 |
| 🔴 判断标准 | 满足任一：头部公司重大发布 / 开源 SOTA 突破 / 融资 ≥$100M / GitHub 日榜⭐>500 或周榜⭐>2000 / 行业格局性政策 / **跨源收敛**（3+ 源报道同一事件） |
| 🟡 判断标准 | 值得关注但不满足🔴：中小公司更新、社区热帖、技术趋势信号、GitHub 日榜⭐200-500 |
| 跨源收敛检测 | 同一事件在 TechCrunch/VentureBeat + HN + Reddit 中任意 3 源出现 → 自动升级为 🔴 |

## Insights 更新格式

每次运行完成后，在工作目录的 `insights.md` 末尾追加：

```markdown
## 实践记录 · {YYYY-MM-DD}

- 板块条目数：算力{N} / 模型{N} / 研究社区{N} / 业界变动{N} / 国际形势{N}
- 遗漏内容：{本次发现的盲区，如"昆仑万维SkyReels-V4未被抓取"}
- 问题：{本次遇到的新问题}
- 改进：{下次可以做的调整}
```
